# Wollok AutoGrader

## Objetivo

Automatizar la corrección de ejercicios realizados en Wollok y almacenados en repositorios Git.

## Principios
- Open Source.
- Software libre.
- Fácil de instalar.
- Modular.
- Incremental.
- Independiente del proveedor Git.
- Tests ocultos para los estudiantes.
- Feedback automático.
